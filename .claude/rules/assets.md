# Brand asset pipelines

- Favicon: `scripts/favicon/crest.ts` (side-effect-free crest builder), `scripts/favicon/variants.ts` (design-round catalogue), `scripts/favicon/glyphs.ts` (Cormorant outlines generated by `scripts/favicon/extract-glyphs.py`), `scripts/generate-favicons.ts` (`npm run favicon`), `scripts/favicon-variants.ts` (`npm run favicon:variants`). The favicon is a family crest: the badge's open arc with three trailing dots per side, always carrying a letter, rendered only from the locked tokens and checked at 16 px with sharp. Rules: `.agent/skills/favicon-builder/SKILL.md`.
- Lockscreen: `scripts/generate-lockscreen.ts` and `scripts/lockscreen/designs.ts` (`npm run lockscreen`, `npm run lockscreen:variants`). sharp composites the brand badge and a `qrcode`-generated QR onto the committed inputs under `public/assets/lockscreen/`; linen-classic is the confirmed final, with an Instagram edition. Realistic composites only, no AI collage. Rules: `.agent/skills/lockscreen-qr-generator/SKILL.md`.
